登录路由器

示意图 · 电脑用网线或 Wi-Fi 连着这台路由器

打开 PowerShell

  1. 1按键盘 Win+R，输入 powershell，回车
  2. 2输入 ssh root@192.168.8.1 回车
  3. 3第一次连会问 yes/no，输入 yes 回车
  4. 4输入 GL 后台的管理密码回车。输入时屏幕上不显示，是正常的
  5. 5看到 root@GL-…:~# 就登录成功了

192.168.8.1 是 GL 路由器的默认地址，改过的话填你自己的。在 PowerShell 里点鼠标右键就是粘贴。

Windows PowerShell
PS C:\Users\你> ssh root@192.168.8.1
The authenticity of host '192.168.8.1 (192.168.8.1)' can't be established.
ED25519 key fingerprint is SHA256:qdIR+KAlqZI+…
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes
⬆ 输入 yes 回车
root@192.168.8.1's password: ⬅ 输入后台密码，输入时不显示，输完回车
root@GL-MT3600BE:~# █
提示 WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!，连不上？
这台电脑以前连过别的 GL 路由器（它们都是 192.168.8.1），或者路由器重置过。确认连的是自己的路由器后，先执行 ssh-keygen -R 192.168.8.1，再重新 ssh root@192.168.8.1。
