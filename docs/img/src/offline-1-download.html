方式二：在电脑上下载离线包

路由器完全连不上 GitHub 时用

打开仓库首页右侧的 Releases（或 github.com/lyr05142002-dot/Q7Y/releases），在最新版本的 Assets 里下载 litebox-arm64-offline.zip：

LiteBox v0.6.1Latest
Assets8
📦 litebox-arm64-offline.zip内核 + 面板 + 脚本22.5 MB
📦 litebox-arm64-offline.zip.sha256校验文件92 Bytes
📦 litebox.tar.gz一键安装命令用的22 KB
📦 litebox.zip只有脚本，安装时联网下载26 KB
📦 mihomo-v1.19.31-source.tar.gz内核源码（GPL 要求附带）1.2 MB
点这个下载（约 22.5MB，路由器不用联网）
解压：右键 zip →「全部解压缩」，得到 litebox 文件夹
📁 litebox
 ├ 📄 install.sh　安装脚本
 ├ 📁 files　服务、命令、配置模板
 ├ 📦 mihomo-linux-arm64-v1.19.31.gz　代理内核
 ├ 📦 dist-no-fonts.zip　网页面板
 └ 📁 licenses　第三方许可证
⚠️ 里面的 .gz 和 dist-no-fonts.zip 不要再解压，安装脚本会自己处理。
⚠️ 不要用记事本打开或修改 install.sh 和 files 里的文件。
