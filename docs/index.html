LiteBox 手机版

和家里路由器同一套分组和分流规则，出门在外也一样：国内直连、AI 单独选节点、其余走代理。

安卓：FlClash / Clash Meta for Android

  1. 安装 App（二选一）： FlClash 或 Clash Meta for Android，下载 arm64-v8a 版本的 apk。

  2. 订阅地址只在这台手机的浏览器里处理，不会上传到任何地方。

  3. 在 App 里导入下载的 litebox-android.yaml： FlClash 是「配置 → 右下角 + → 文件」；Clash Meta 是「配置 → 新配置 → 导入文件」。选中它，回首页打开开关。
  4. 第一次启动会经代理下载分流规则，等十几秒再用。在 App 的「代理」页可以给「🤖 AI」单独选节点。

iPhone：Shadowrocket

  1. 在 App Store（非中国大陆区账号）安装 Shadowrocket。
  2. Shadowrocket 首页右上角 +，类型选 Subscribe，填机场订阅地址并保存。
  3. 导入 LiteBox 规则配置：
    一键导入 Shadowrocket

    一键导入没反应时：复制地址，在 Shadowrocket「配置 → 右上角 +」粘贴下载。

  4. 在「配置」页点刚下载的 shadowrocket.conf →「使用配置」，回首页「全局路由」选「配置」，打开开关。
分流规则来自 liandu2024/clash 和 MetaCubeX/meta-rules-dat，每天自动更新。 路由器版和源码：lyr05142002-dot/Q7Y
