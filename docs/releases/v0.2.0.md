## v0.2.0 更新

**手机版**（安卓 + iPhone）：和路由器同一套分组和分流规则，出门在外也一样分流。手机浏览器打开 https://lyr05142002-dot.github.io/Q7Y/ ，安卓填订阅地址生成 FlClash / Clash Meta 配置，iPhone 一键导入 Shadowrocket。

**分流和兼容性改进：**
- 默认屏蔽走代理的 QUIC（UDP 443），浏览器退回 TCP，节点 UDP 差时 YouTube 等更流畅；`litebox quic on|off` 切换
- 国内 IP 规则加 `no-resolve`：有域名的连接只按域名判断，不再为匹配 IP 段解析每个境外域名
- `litebox stack system|gvisor|mixed` 切换 TUN 协议栈；`litebox doctor` 发现开着硬件流量卸载、局域网 IPv6 时提示

**更稳：**
- 看门狗自愈：内核反复崩溃、系统放弃重启时，先尝试拉起，拉不起来就恢复原来的 DNS，不会全家断网；内核恢复后自动重新接管
- `litebox update` 一键升级；`litebox update --reset-config` 用新模板重新生成配置（订阅、端口、密钥保留）
- 连不上规则下载地址时不再逐个等超时，安装从约 3 分钟缩短到约 1 分钟

**从 v0.1.x 升级：** `litebox update --reset-config`（想保留自己改过的配置就去掉 `--reset-config`，但用不上 QUIC 开关和 no-resolve）。

本版在 OpenWrt 21.02.7 上测试过：安装、升级、`--reset-config`、局域网设备透明代理、QUIC 屏蔽（境外拒绝、国内放行）、三种协议栈、看门狗自愈（含 stop 与看门狗的竞态）、`litebox update` 实际联网升级；安卓配置生成页面在手机尺寸浏览器里测试过，生成的配置通过 mihomo 检查。

GL.iNet **GL-MT3600BE（Beryl 7）** 等小内存 OpenWrt 路由器的轻量透明代理：mihomo 内核 + zashboard 网页面板 + 分流规则，常驻内存目标 200MB 以内。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **litebox-arm64-offline.zip** | **推荐**。已带 mihomo 内核和面板，路由器连不上 GitHub 也能装。适用于 aarch64 路由器（GL-MT3600BE 等） |
| litebox.zip | 只有脚本，安装时联网下载内核和面板，支持 aarch64 / armv7 / x86_64 |
| litebox.tar.gz | 给路由器上的一键安装命令（`get.sh`）用，一般不用手动下载 |
| mihomo-v1.19.31-source.tar.gz | mihomo v1.19.31 源码（GPL-3.0 要求随二进制提供），安装用不到 |

每个文件都附有 `.sha256` 校验文件。

## 安装

1. 下载 **litebox-arm64-offline.zip** 并解压，得到 `litebox` 文件夹
2. 用 HexHub（SFTP）或 `scp -O -r litebox root@192.168.8.1:/tmp/` 上传到路由器的 `/tmp/`
3. SSH 登录路由器执行：
   ```
   sh /tmp/litebox/install.sh --sub '你的机场订阅地址'
   ```
4. 复制安装结束时显示的**一键登录链接**到浏览器，进入面板

路由器能访问 GitHub 的话，也可以直接一条命令：

```
curl -fsSL https://raw.githubusercontent.com/lyr05142002-dot/Q7Y/main/get.sh | sh -s -- --sub '你的机场订阅地址'
```

完整的图文教程见 [README](https://github.com/lyr05142002-dot/Q7Y#图文安装教程)。

## 包含的组件

- mihomo **v1.19.31**（GPL-3.0）
- zashboard **v3.29.1**（MIT，无字体版）
- 内核和面板都锁定版本，安装时校验 SHA256

## 注意

- 只在 GL 官方固件（OpenWrt 21.02）环境下设计，**尚未在真机上验证**。第一次安装建议用网线连着路由器；上不了网时执行 `litebox direct` 立即恢复直连
- 安装前请在 GL 管理界面关闭 VPN 客户端、AdGuard Home 和其他代理插件
