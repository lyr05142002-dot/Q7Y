## v0.5.0 更新

参考 Open-Box 的界面，补上面板里缺的几样东西：

- **新的概览页**（`http://路由器IP:9090/ui/litebox/`，安装完和 `litebox panel` 都会显示带密码的链接）
  - 百度 / Google / OpenAI / GitHub 四个站点的延迟和最近 24 次走势，每分钟自动测一次
  - 连接数、内存、下载 / 上传速率的实时曲线
  - 分流统计：经过内核的连接里代理 / 直连 / 拦截各多少，规则命中排行，域名流量排行
  - 流量洞察：按月看每天的流量（看门狗每 5 分钟记一次，每小时存回闪存）
- **路由测试**：输入域名，浏览器真实访问一次，显示 DNS（FakeIP 还是真实 IP）、怎么进的内核、命中哪条规则、最终走哪个分组和节点、访问是否成功。看页面的设备本身就是局域网终端，不用模拟设备
- **`litebox route 域名`**：在 SSH 里让路由器自己访问一次，输出同样的信息
- **分组带图标**：🚀 节点选择、♻️ 自动选择、🤖 AI、📺 流媒体、🐟 漏网之鱼在 zashboard 里显示对应图标（内嵌 SVG，不依赖外网）
- 在 zashboard 里点「更新面板」把面板目录整个换掉后，看门狗会把概览页补回去

**从旧版升级**：执行 `litebox update --reset-config`（订阅、面板密码保留）。不加 `--reset-config` 也能用上概览页和路由测试，只是分组没有图标。

GL.iNet **GL-MT3600BE（Beryl 7）** 等小内存 OpenWrt 路由器的轻量透明代理：mihomo 内核 + zashboard 网页面板 + 分流规则。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **litebox-arm64-offline.zip** | **推荐**。已带 mihomo 内核和面板，路由器连不上 GitHub 也能装。适用于 aarch64 路由器（GL-MT3600BE 等） |
| litebox.zip | 只有脚本，安装时联网下载内核和面板，支持 aarch64 / armv7 / x86_64 |
| litebox.tar.gz | 给路由器上的一键安装命令（`get.sh`）用，一般不用手动下载 |
| mihomo-v1.19.31-source.tar.gz | mihomo v1.19.31 源码（GPL-3.0 要求随二进制提供），安装用不到 |

每个文件都附有 `.sha256` 校验文件。完整的图文教程见 [README](https://github.com/lyr05142002-dot/Q7Y#图文安装教程)。

## 包含的组件

- mihomo **v1.19.31**（GPL-3.0）
- zashboard **v3.29.1**（MIT，无字体版）
- 内核和面板都锁定版本，安装时校验 SHA256
