## v0.5.1 更新

- **常用应用各自一个分组，带应用图标**（和 Open-Box 的「代理 · 策略」页一样一目了然）：YouTube、Netflix、Google、GitHub、Telegram、X、TikTok
  - 默认都跟随「🚀 节点选择」，不用额外设置；想让某个应用单独走某个节点（比如 Netflix 选解锁好的地区），在面板里改它就行
  - 图标是内嵌的 SVG，不依赖外网；深色主题下黑色图标（GitHub、X、TikTok）自动变白
  - 原来的「📺 流媒体」拆成 YouTube 和 Netflix 两个分组
  - 新增 TikTok 规则（MetaCubeX/meta-rules-dat）
- 概览页里 Google、GitHub 的延迟改为经各自的分组测，和平时访问走同一条线

**从旧版升级**：执行 `litebox update --reset-config`（订阅、面板密码保留，之前在面板里选的节点需要重新选一次）。

手机版（安卓、Shadowrocket）保持原来的分组，界面更简洁，规则不变。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **litebox-arm64-offline.zip** | **推荐**。已带 mihomo 内核和面板，路由器连不上 GitHub 也能装。适用于 aarch64 路由器（GL-MT3600BE 等） |
| litebox.zip | 只有脚本，安装时联网下载内核和面板，支持 aarch64 / armv7 / x86_64 |
| litebox.tar.gz | 给路由器上的一键安装命令（`get.sh`）用，一般不用手动下载 |
| mihomo-v1.19.31-source.tar.gz | mihomo v1.19.31 源码（GPL-3.0 要求随二进制提供），安装用不到 |

每个文件都附有 `.sha256` 校验文件。完整的图文教程见 [README](https://github.com/lyr05142002-dot/Q7Y#图文安装教程)。

## 包含的组件

- mihomo **v1.19.31**（GPL-3.0）
- zashboard **v3.29.1**（MIT，无字体版）
- 内核和面板都锁定版本，安装时校验 SHA256
