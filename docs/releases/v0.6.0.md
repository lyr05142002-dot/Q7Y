## v0.6.0 更新

### 订阅地址好填了

- **路由器后台多了「服务 → LiteBox」页面**：订阅地址框在最上面，粘贴、点「保存并启动」就生效；下面显示加载了几个节点、套餐用了多少流量、哪天到期，还有「更新节点」「打开面板」「重启」「停用（恢复直连）」按钮。需要 LuCI 21.02 或更新版本（iStoreOS、ImmortalWrt 21.02+、OpenWrt 21.02+ 都自带），安装时自动加上
- **安装时问订阅更清楚**：显示一个说明框（订阅地址是什么、在机场网站哪里复制、怎么粘贴），粘错了（不是 https:// 开头）会让你重新粘；多复制的空格、引号自动去掉。之前装了但没填订阅的，重新运行安装命令也会问
- **概览页最上面加了「机场订阅」卡片**：节点数、套餐流量进度条、到期日、上次更新时间、「更新节点」按钮，以及去哪里改订阅
- `litebox sub` 保存后会等节点下载好，告诉你加载了几个；新增 `litebox sub-update`（重新拉节点）、`litebox enable`（和 `direct` 相反）

### AI 各自一个分组

- 新增 **ChatGPT、Claude、Gemini、Copilot、Grok** 分组，带各自的图标，默认跟随「🤖 AI」：改「🤖 AI」就全部跟着变，也可以单独给某一个换节点
- 修复：作者的 AI 总名单原来排在最前面，里面的 openai.com、claude.ai 等让具体的 ChatGPT / Claude 名单从来匹配不到；总名单里的 x.com、googleapis.com、gstatic.com 还会把 X、Google 的流量抢到「🤖 AI」。现在顺序是：具体 AI 名单 → 常用应用 → AI 总名单。手机版配置同步调整

### 检查出来的问题，一并修复

- **没填订阅时开机不再启动内核**：以前装好但没填订阅，重启路由器后内核会启动并接管 DNS，境外网站却没有节点可用
- **防火墙加速层加锁**：开机时内核启动和防火墙重载会同时加删规则，偶尔导致规则重复或状态显示不对
- **安装时不再误判冲突插件**：只看开机自启、真实进程，不信插件自己的 running（有的固件没进程也说在运行），避免把本来关着的插件记下来、切回时反而打开
- **安装时不再误改 AdGuard Home 的 DNS**：只在 DNS 指向的本机端口已经没人监听时才改回默认
- 安装时缺 curl 会顺手装上（查节点、自检、路由测试、流量统计都要用）
- `litebox doctor` 检查的冲突插件列表和安装脚本一致
- LuCI 页面文件权限固定为 644；分组图标的许可证说明随所有安装包附带（`licenses/`）

**从旧版升级**：执行 `litebox update --reset-config`（订阅、面板密码保留；新分组需要在面板里重新选一次节点）。升级后在路由器后台「服务 → LiteBox」就能看到新页面；第一次打开如果提示没有权限，退出后台重新登录一次。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **litebox-arm64-offline.zip** | **推荐**。已带 mihomo 内核和面板，路由器连不上 GitHub 也能装。适用于 aarch64 路由器（GL-MT3600BE 等） |
| litebox.zip | 只有脚本，安装时联网下载内核和面板，支持 aarch64 / armv7 / x86_64 |
| litebox.tar.gz | 给路由器上的一键安装命令（`get.sh`）用，一般不用手动下载 |
| mihomo-v1.19.31-source.tar.gz | mihomo v1.19.31 源码（GPL-3.0 要求随二进制提供），安装用不到 |

每个文件都附有 `.sha256` 校验文件。完整的图文教程见 [README](https://github.com/lyr05142002-dot/Q7Y#图文安装教程)。

## 包含的组件

- mihomo **v1.19.31**（GPL-3.0）
- zashboard **v3.29.1**（MIT，无字体版）
- 内核和面板都锁定版本，安装时校验 SHA256
