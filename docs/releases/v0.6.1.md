## v0.6.1 更新

- **概览页的 OpenAI 换成 Claude**：延迟经「Claude」分组测，和平时访问 Claude 走同一条线
- **新增「节点稳定性」**：每个节点访问 Claude 的成功率、平均延迟和最近 20 次结果（一个点一次：绿色正常、黄色慢、红色失败），也能切到 Google、GitHub 看
  - 标出 Claude 现在实际走的节点和最稳的节点；点「用这个」直接把 Claude 分组切到那个节点
  - 页面开着时每 10 分钟自动测一次，也可以手动「测试全部节点」；每次每个节点只取一次响应头，几 KB 流量
  - 最近 10 次结果记在路由器内核里，换设备打开也看得到；更早的存在本机浏览器里
  - 点概览里的 Claude 卡片会跳到这里
- 发布前多检查一项：概览页和路由器后台页面的脚本能正常解析
- 图文更新：截图换成新版界面；教程配图里的 SSH 指纹、示例密码、示例订阅地址都打了码

**从 v0.6.0 升级**：执行 `litebox update`（不用 `--reset-config`，分组没变）。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **litebox-arm64-offline.zip** | **推荐**。已带 mihomo 内核和面板，路由器连不上 GitHub 也能装。适用于 aarch64 路由器（GL-MT3600BE 等） |
| litebox.zip | 只有脚本，安装时联网下载内核和面板，支持 aarch64 / armv7 / x86_64 |
| litebox.tar.gz | 给路由器上的一键安装命令（`get.sh`）用，一般不用手动下载 |
| mihomo-v1.19.31-source.tar.gz | mihomo v1.19.31 源码（GPL-3.0 要求随二进制提供），安装用不到 |

每个文件都附有 `.sha256` 校验文件。完整的图文教程见 [README](https://github.com/lyr05142002-dot/Q7Y#图文安装教程)。

## 包含的组件

- mihomo **v1.19.31**（GPL-3.0）
- zashboard **v3.29.1**（MIT，无字体版）
- 内核和面板都锁定版本，安装时校验 SHA256
